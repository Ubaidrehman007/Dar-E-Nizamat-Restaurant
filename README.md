# Dar E Nizamat (दर निज़ामात) | Luxury Mughlai Restaurant Website

A responsive multi-page static website created for **Dar E Nizamat (दर निज़ामात)**, a fine dining Mughlai restaurant located in Mumbra, Thane. The site features an obsidian and gold luxury design system inspired by haute cuisine dining lounges, built entirely with semantic HTML5 and modern CSS3.

## ✨ Features & Highlights

- **Pure CSS Responsive Navigation:** Includes an accessible CSS-only checkbox hamburger menu drawer for tablets and smartphones without requiring external JavaScript.
- **Fluid Layouts:** Uses CSS Grid (`grid-template-columns`) and Flexbox to deliver layout adaptation across desktop screens down to 320px mobile viewports.
- **Glassmorphic Surface Design:** Built with frosted backdrop filters (`backdrop-filter: blur()`), gold accent borders, and hover micro-interactions.
- **Google Maps & Verified Reviews Integration:** Displays authentic customer reviews and pinpoint directions to _Elite C, opposite Palm Riviera, Mumbra, Thane_.
- **Integrated Reservation Suite:** Front-facing inquiry and table-booking form ready for backend mailer integration.

---

## 🛠️ Built With

- **HTML5:** Semantic architecture (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
- **CSS3:** Custom scrollbars, fluid typography (`clamp()`), keyframe animations, and media queries
- **Google Fonts:**
- `Cinzel` (Primary headings and brand accents)
- `Playfair Display` (Serif subheadings and quotes)
- `Plus Jakarta Sans` (Clean modern body text)

- **FontAwesome v6.5:** Vector icons for navigation, amenities, and contact metadata

## 🚀 Getting Started Locally

1. **Clone the repository:**

```bash
git clone https://github.com/ubaidrehman007/Dar-E-Nizamat-Restaurant.git

```

2. **Navigate to the project folder:**

```bash
cd Dar-E-Nizamat-Restaurant

```

3. **Open the website:**

- Double-click `index.html` to run it directly in your preferred web browser, or
- Launch with VS Code **Live Server** extension (`Alt + L, Alt + O`).
